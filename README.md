# Korenet

Ever feel like your client and the server are having two completely different conversations?  
Yeah. Korenet shows you *what’s actually happening*.

## What it does

- Provides real-time **network feedback** between client and server
- Exposes latency, timing, and sync quirks instead of hiding them
- Acts as a foundation for HUDs, diagnostics, and feedback-based mods

No magic. No fixes. Just visibility.

## Why does this exist?

Because guessing is worse than knowing.  
And “probably ping” isn’t very helpful without data.

## Use cases

- Visual feedback for latency / timing
- Desync-aware HUDs
- Debugging client ↔ server behavior
- Mods that need *accurate* network insight

## What it is **not**

- ❌ An optimization mod
- ❌ A lag fixer
- ❌ A PvP buff
- ❌ Server-side spyware

## Notes

- Client-side only
- Servers don’t know
- Servers don’t care
- You get the truth anyway
